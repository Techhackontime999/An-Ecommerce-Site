# Contributors

Shop-Seed is developed and maintained by its owner and the open-source
contributors listed below. Thank you to everyone who has helped improve the
platform — bug reports, fixes, features, tests, and documentation all count.

By submitting a contribution you agree to the
[Contributor License Agreement](./CLA.md). If you would like to be credited,
make sure your GitHub username (or the name/handle you want shown) is accurate
on the pull request.

### How to add yourself

1. After your pull request is merged, update the table above and open a new
   PR titled `docs: add <your name> to CONTRIBUTORS.md`.
2. Or, mention in your original PR description that you'd like to be credited
   and the maintainer will add you on merge.

> Contributors may mention their work on this project on their own resumes,
> portfolios, or social profiles. Listing yourself as a **maintainer** or
> **owner**, or claiming ownership of the project or its code, is not allowed.
